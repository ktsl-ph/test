INFANT WEIGHT PERCENTILE CALCULATOR
===================================

Your calculator is ready! Since you're using Cursor Web, follow these steps:

OPTION 1: Download Individual Files
-----------------------------------
1. In Cursor's file explorer (left sidebar), find these files:
   - index.html
   - styles.css  
   - script.js

2. Right-click on each file → "Download" (or look for download option)

3. Save all 3 files to the same folder on your computer

4. Double-click index.html to open in your browser

OPTION 2: Download Archive
--------------------------
1. Download the file: calculator.tar.gz
2. Extract it on your computer
3. Open index.html in your browser

HOW TO USE THE CALCULATOR
------------------------
1. Select infant's gender (Male/Female)
2. Enter age in months (0-24)
3. Enter weight in kilograms  
4. Click "Calculate Percentile"
5. View results with color-coded interpretation

FEATURES
--------
- Based on WHO growth standards
- Works for infants 0-2 years old
- Mobile responsive design
- Color-coded results (green=normal, red=underweight, orange=overweight)
- Medical disclaimer included

TROUBLESHOOTING
--------------
- Make sure all 3 files are in the same folder
- Use a modern browser (Chrome, Firefox, Safari, Edge)
- Enable JavaScript in your browser

The calculator works completely offline once downloaded!
